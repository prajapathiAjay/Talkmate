# JubJub - frontend

React 18 + Vite + Tailwind CSS 4 client for JubJub.

See the [main README](../README.md) for screenshots, features, setup and the API.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

Theme colours live at the top of `src/index.css`.
